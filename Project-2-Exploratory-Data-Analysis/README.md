# Project 2: Exploratory Data Analysis

## 📌 Objective
The objective of this project is to analyze an e-commerce sales dataset to identify patterns, trends, distributions, and key insights using descriptive statistics.

## 🛠️ Tools Used
- Microsoft Excel
- Descriptive Statistics
- Data Visualization

## 📂 Dataset
The dataset contains **1,200 e-commerce order records** with information such as products, quantities, unit prices, payment methods, order status, referral sources, and total order prices.

## 📊 Analysis Performed
- Calculated descriptive statistics (Mean, Median, Count)
- Identified trends in sales data
- Analyzed product-wise revenue
- Examined payment method distribution
- Analyzed order status distribution
- Detected outliers using the IQR method
- Summarized key business observations

## 📈 Charts Included
- Revenue by Product
- Monthly Revenue Trend
- Payment Method Distribution
- Order Status Distribution

## 🔍 Key Insights
- The dataset contains **1,200 orders**.
- Average order value is **Rs. 1,053.97**.
- The median order value is **Rs. 823.62**, indicating a right-skewed distribution.
- Chairs, Printers, and Laptops generated the highest revenue.
- Only a few high-value orders were identified as statistical outliers.
- Revenue remained relatively stable throughout the observed period.
